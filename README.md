# Hithlain

*/ˈhɪθ.laɪn/ — HITH-line*  
*— noun*

1) A strong yet light thread of Elvish craft, grey as gathered mist and soft as silk beneath the hand; woven in Lórien by arts unspoken, whose making was hidden from all save those who wrought it.

2) A lightweight engine for weaving branching RPG stories, choices, and game state into playable text adventures.
